# C# Program of Seasons

## 📌 Overview
A simple C# application that determines the season of the year based on a user-provided month number. It uses conditional logic to map numerical inputs to their corresponding seasons.

## 🚀 Features
- Prompts the user to enter a month number (1–12).
- Evaluates the input using conditional statements.
- Displays the corresponding season:
  - **Winter** (12, 1, 2)
  - **Spring** (3, 4, 5)
  - **Summer** (6, 7, 8)
  - **Autumn** (9, 10, 11)
- Displays an "Invalid Month" message for out-of-range inputs.
